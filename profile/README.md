# Tinance 元安

**Token + Finance：给 AI Agent 用的投研基础设施**

市面上的投研工具大多是给人用的：终端、网页、报表。
Tinance 做的是给 AI Agent 用的那一层：数据提前加工好，能力封装成标准接口，Agent 一句话就能调用，不用再搜网页、翻公告、拼数据。

## 理念

- **Agent-first**：以标准接口服务 Agent，优先做好机器调用体验。
- **开箱即用**：完成清洗、实体匹配和事件结构化，拿到即可分析。
- **可追溯**：保留来源、时间和处理口径，让分析有据可查。
- **可组合**：通过查询接口、事件订阅等能力，支持不同 Agent 自由编排。

| 投研数据 | 行情、财务、指数等基础数据，以及经 AI 加工的市场逻辑与专题数据 | 🚧 建设中 |

通过 MCP + Skill 接入你常用的 AI 工具，然后直接用自然语言提问。
