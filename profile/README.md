# Tinance 元安

**Token + Finance：给 AI Agent 用的投研基础设施与数据**

市面上的投研工具大多是给人用的：终端、网页、报表。
Tinance 做的是给 AI Agent 用的那一层：数据提前加工好，能力封装成标准接口，Agent 一句话就能调用，不用再搜网页、翻公告、拼数据。

## 理念

- **Agent-first**：服务对象是 Agent，不做终端，不重前端
- **开箱即用**：数据和逻辑预先处理好，用户只管提问
- **数据与逻辑解耦**：只提供数据和能力，展示方式交给调用方的 AI 自由组合
- **基础设施**：公司事件总线等

## 我们在做什么

| 方向 | 内容 | 状态 |
|---|---|---|
| 投研数据 | 行情、财务、指数等基础数据，以及经 AI 加工的市场逻辑与专题数据 | 🚧 建设中 |
| MCP 服务 | 以 MCP 协议提供统一的数据与能力接入 | 🚧 建设中 |
| Skills | 面向投研场景的 Agent Skill，一次安装即可使用 | 🚧 建设中 |
| 更多基础设施 | 围绕 Agent 投研工作流的工具与组件 | 📋 规划中 |

## 怎么用

通过 MCP + Skill 接入你常用的 AI 工具，然后直接用自然语言提问。
具体接入方式见各仓库说明。
